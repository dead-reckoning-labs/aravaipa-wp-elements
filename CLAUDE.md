# Aravaipa Elements

Cornerstone elements plugin for aravaiparunning.com. See README.md for elements and build.

## Design

- **No color bars. Ever.** Never put a thin colored accent stripe on any edge (top, left, right, bottom) of a card, panel, callout, quote, modal, mockup, slide, or graphic. Brand color goes on buttons, progress, chips, and imagery instead. Jamil banned it 2026-10-08.
